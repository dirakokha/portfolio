# تصویرها

این پوشه مقصد بارگذاری تصویرها از پنل مدیریت است (`public/media`).
هر فایل تصویری که از طریق `/admin` بارگذاری شود، اینجا قرار می‌گیرد و
در سایت با نشانی `/media/نام-فایل` استفاده می‌شود.

فایل‌های پرترهٔ فعلی سایت:

| فایل | کاربرد | اندازه |
| --- | --- | --- |
| `portrait-960.webp` | نسخهٔ بزرگ بخش نخست (تصویر اصلی) | ۹۶۰×۱۲۰۰ |
| `portrait-480.webp` | نسخهٔ موبایل، از طریق `srcset` | ۴۸۰×۶۰۰ |
| `portrait-print.webp` | پرترهٔ کوچک رزومهٔ چاپی (۳۰ میلی‌متر) | ۳۶۰×۴۵۰ |

هر سه فایل از یک عکس مبدأ ساخته شده‌اند: سیاه‌وسفید، سطح سیاه اصلاح‌شده تا
پس‌زمینهٔ عکس در شبی که رنگ هیرو است حل شود. هیچ فیلتر یا ماسک CSS استفاده
نمی‌شود، بنابراین در همهٔ مرورگرها و در چاپ یکسان دیده می‌شود.

اگر از `/admin` تصویر دیگری بارگذاری شود، فقط همان فایل در بخش نخست استفاده
می‌شود و نسخهٔ رزومه دست‌نخورده می‌ماند. تا وقتی تصویری انتخاب نشده باشد،
بخش نخست کاملاً تایپوگرافی است و هیچ جای‌نگهدار ساختگی نمایش داده نمی‌شود.
